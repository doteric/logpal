Logging, reconsidered

Stop collecting breadcrumbs.

Traditional logging scatters an event’s context across a trail of messages. When you need an answer, you are left reconstructing a story from fragments.

Build one useful record of what happened — from start to finish.

A calmer logging flow

Context in. A complete event out.

Designed around the request or invocation, not the individual log statement.

01 / EVENT-SCOPED

Start with an event

Create one event per invocation. AsyncLocalStorage keeps it available to the helpers doing the real work.

02 / ENRICH AS YOU GO

Add the useful bits

Attach data, upstream responses, warnings, and errors at the point where they become known.

03 / FINALIZE ONCE

Leave with confidence

LogPal finalizes automatically, applies sampling, and flags incomplete data with clear diagnostics.

$ npm install logpal

import initLogPal from 'logpal';

const logpal = new initLogPal({
  eventType: 'checkout',
  format: 'httpRequest',
});

await logpal.event({ requestId: 'req_7z2k' }, async () => {
  logpal.addData({
    request: { path: '/checkout', method: 'POST' },
  });

  const response = await processCheckout();
  logpal.addData({
    response: { statusCode: response.status, durationMs: 84 },
  });
});
