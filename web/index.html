01 / Inconsistent logs

Problem (Why?)

Applications use different log formats and record different details. Information about one request is often spread across several messages, making it hard to follow what happened. Missing request IDs or outcomes make those messages harder to connect.

02 / A shared approach

Solution (How?)

Logging needs a shared format and clear rules for what to record. A simple, minimal interface would make this consistent across applications, with one record per event where practical.

03 / Node.js package

LogPal (What?)

LogPal collects data during a request or invocation and writes a JSON log when the handler finishes. It includes HTTP and Lambda formats, inferred TypeScript types, and Zod validation.

01logpal.event()↗

Create an event

One instance per app. One event per invocation, available to every helper.

02logpal.addData()↗

Add data

Add event fields here. Use addError(), addWarning(), and initExternalCall() for issues and outgoing calls.

03// automatic↵

Finalize the log

When the handler finishes, LogPal validates event data and writes JSON to the console by default. Validation issues appear in _logpal.errors.

Getting started

Install and configure

Install the package, create one instance for your app, and wrap each handler in an event.

$npm install log-pal
handler.tsTypeScript 
import LogPal from 'log-pal';

// One instance for your application.
const logpal = new LogPal({
  eventType: 'req-summary-log',
  format: 'httpRequest',
  logInitialization: false,
});

export const handleRequest = (
  request: { requestId: string; path: string; method: string },
  handle: () => Promise<{ statusCode: number }>,
) =>
  logpal.event({ requestId: request.requestId }, async () => {
    const startedAt = performance.now();
    logpal.addData({
      request: { path: request.path, method: request.method },
    });

    const response = await handle();
    logpal.addData({
      response: {
        statusCode: response.statusCode,
        durationMs: performance.now() - startedAt,
      },
    });
    return response;
  });
